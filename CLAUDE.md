# 3EAS CORTEX — 3eascortex.com

Static site on GitHub Pages. Almost everything lives in one file: `index.html` (~8k lines, inline CSS + JS).
Two Cloudflare Workers sit beside it, deployed separately:

- `shop/` — Stripe checkout + R2 downloads for TRANSMISSIONS and merch. Details: shop/README.md
- `worker/` — backend for the A.I. BABY chat panel. Details: worker/README.md
- `media/pipeline.mjs` — encodes audio from `media/inbox/`, uploads to R2, rewrites track lists in `index.html` and `media/catalog.json`

## Run locally
- Site: `python3 -m http.server 8080` from repo root
- Shop: `cd shop && npm run dev` (port 8788, mock mode)
- Chat: `cd worker && npm run dev` (port 8787, mock mode)
- Music/merch: `node media/pipeline.mjs --dry-run` first, then without the flag; `--sync` after editing prices or `media/merch.json`

## Rules
- Edit `index.html` with targeted edits; never rewrite or reformat the whole file.
- After any change to `index.html`, syntax-check the inline scripts and load the page locally.
- Track lists and prices are generated by the pipeline. Change them through `media/catalog.json` + `--sync`, not by hand.
- Secrets go in `.dev.vars` (gitignored) or `wrangler secret put`, never in `wrangler.toml` or committed files.
- Never deploy a Worker, flip `MOCK_MODE`, set `SHOP_PROD_URL`, or push to `main` without asking first.
- After a `--local` pipeline run, restore `index.html` and `media/catalog.json` before committing.
