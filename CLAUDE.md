# 3EAS CORTEX — 3eascortex.com

Static site on GitHub Pages. Almost everything lives in one file: `index.html` (~8k lines, inline CSS + JS).
Two Cloudflare Workers sit beside it, deployed separately:

- `shop/` — Stripe checkout + R2 downloads for TRANSMISSIONS and merch. Details: shop/README.md
- `worker/` — backend for the A.I. BABY chat panel. Details: worker/README.md
- `media/pipeline.mjs` — encodes audio from `media/inbox/`, uploads to R2, rewrites track lists in `index.html` and `media/catalog.json`

## Run locally
- Site: `python3 -m http.server 8080` from repo root
- Shop: `cd shop && npm run dev` (port 8788, mock mode)
- Chat: `cd worker && npm run dev` (port 8787, mock mode)
- Music/merch: `node media/pipeline.mjs --dry-run` first, then without the flag; `--sync` after editing prices or `media/merch.json`

## Rules
- Edit `index.html` with targeted edits; never rewrite or reformat the whole file.
- After any change to `index.html`, syntax-check the inline scripts and load the page locally.
- Track lists and prices are generated by the pipeline. Change them through `media/catalog.json` + `--sync`, not by hand.
- Secrets go in `.dev.vars` (gitignored) or `wrangler secret put`, never in `wrangler.toml` or committed files.
- Never deploy a Worker, flip `MOCK_MODE`, set `SHOP_PROD_URL`, or push to `main` without asking first.
  - Exception: the words "ticker" and "feed" are the OK. "Ticker" = add/edit/remove ticker lines; "feed" = add/edit/remove videos in `feed/videos.json`. Commit and push to `main` without asking again. Everything else still needs a yes first.
  - A bare YouTube / TikTok / Instagram link sent on its own (no other instruction) counts as "feed": add it to the top of SIGNAL FEED (after the Democracy Now! block) and push.
  - Likewise a standalone ticker-style line (a statement, quote or name, optionally with a non-video link) counts as "ticker": add it under today's LA date marker and push. If a message could be either a ticker line or a question/instruction to Claude, ask instead of posting.
- After a `--local` pipeline run, restore `index.html` and `media/catalog.json` before committing.

## Voice
3EAS-only copy. Say "Chicano", never "Latin". Pirate-signal / noir tone; no generic marketing language.

## Signal feed
`/feed/` is a vertical swipe feed (YouTube, TikTok, Instagram). Videos live in `feed/videos.json`, newest first:
- YouTube: `{"id": "<11-char id>", "caption": "..."}`
- TikTok: `{"src": "tt", "id": "<numeric id from /video/<id>>", "url": "<link>", "caption": "..."}`
  (short vt.tiktok.com links can't be resolved here; ask for the full tiktok.com/@user/video/... link)
- Instagram Reel/post: `{"src": "ig", "id": "<code from /reel/<code>/ or /p/<code>/>", "kind": "reel"|"p", "url": "<link>", "caption": "..."}`
- IG/TikTok Stories can't be embedded (24h, no embed API).
New entries get `"added": "<today, LA date YYYY-MM-DD>"` and go right after the DN block in the file. On the page, the newest of (latest upload, DN week) shows first, then the other, then everything else shuffled per visit.
Only add links the user sends — except the one automation below.
- Automation: `.github/workflows/dn-headlines.yml` runs `scripts/dn-headlines.mjs` each weekday and puts the
  single most recent Democracy Now! "Headlines" video in the feed (entry tagged `"tag": "dn"`).
  Only one is ever up; the next one replaces it.
  Test without network: `DN_RSS_FILE=a.xml DN_SEARCH_FILE=b.html DN_TODAY=YYYY-MM-DD node scripts/dn-headlines.mjs --dry-run`. The only way in from the home page
is the hidden `#feedDoor` above the hero logo (hover / first tap glitches it in).
